# Sonmira 声沚 brand mark

沚 (zhǐ) is a small island in water. The mark is a low islet on the horizon with three ripples beneath it.

| File | Use |
| --- | --- |
| `sonmira-mark.svg` | Mark only, ink `#1F1D1A`, transparent background. For light surfaces and next to the wordmark. |
| `sonmira-mark-light.svg` | Mark only, paper `#F8F5EF`, transparent background. For dark surfaces. |
| `app-icon-ivory.svg` / `app-icon-ivory-1024.png` | App icon on ivory. Full square; iOS applies the rounded mask. |
| `app-icon-ink.svg` / `app-icon-ink-1024.png` | App icon on ink. |

The SVGs are plain shapes with no fonts or effects, so they scale to any size.
